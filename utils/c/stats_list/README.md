# stats_list

`stats_list` lists the persisted statistics of a Yuneta stats store. You can filter by group, variable name, metric, units, and time range. Options give a recursive traversal and raw output.

## Usage

```bash
stats_list [--path <dir>] [--group <g>] [--variable <v>] [--from <t>] [--to <t>] [options]
```

Run `stats_list --help` to see all the options.
