# modules/c/modbus

This module has the Modbus master protocol GClass, `C_PROT_MODBUS_M`. They give the framing that connects industrial and IoT devices that use Modbus RTU or TCP. The framing does not depend on the transport.

To use Modbus in your yuno, find the build option `MODULE_MODBUS` in `modules/c/modbus/Kconfig` and enable it in `menuconfig`.
