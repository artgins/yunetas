Yuneta 7.29.0: a backup of what retention takes, at the same speed

7.29.0 lets retention keep what it takes: tranger2_archive_key_files() leaves the purged files of a key in a batch, and the new yunos archive_sender and archive_keeper take the batches to a backup machine, each file checked by its sha256, over mutual TLS. Against 7.28.8, the last release with a study, 41 of 47 figures stay inside their noise; the six that move, three faster and three slower by 2 to 4%, run code that did not change, and moved as much when only the placement of the code changed.

Prices paid on purpose

What got slower, how much, in which release, and what it buys.

None. Three figures measured slower outside their noise: the TCP echo -2.7% (t = -4.3), the TLS echo -3.1% (t = -3.6) and the treedb save +4.3% of time (t = 5.5). None runs code that changed. Relinked with the libraries of 7.28.11, the 7.29.0 binaries measured the treedb save within 0.85% and the TCP echo within 1.9% of it, and swapping only one library whose hot code is the same moved each as much the other way. The TLS echo moved in steps of 1% over 7.28.10, 7.28.11 and 7.29.0, none outside its noise, and the TLS echo that also stores every message, the same TLS code, measured +1.3%: code placement, not code. Three figures measured faster for the same reason, and are not claimed.

How it was measured

7.29.0 against 7.28.8. Written on 2026-10-28, before the tag. 7.29.0 is the C code of main at 74ad0287b with its version raised (no C after it), measured against 7.28.8, the last release with a study; 7.28.9 to 7.28.11 shipped none, so the study covers them too. 7.29.0 adds the archive of retention to timeranger2 (new functions; the append and read paths do not change), the incremental sha256 to gobj-c, the peer certificate to ytls and C_TCP (after a TLS handshake), and two new yunos; 7.28.9 to 7.28.11 changed the date reading of gobj-c, C_WEBSOCKET and C_YUNO. Measured: every benchmark whose binary links that code -- timeranger2, treedb, C_TREEDB, the rotatory, the inter-yuno events, the TCP and TLS echoes and the BFF logins (47 figures); the raw event loop and MQTT run none of it. The 7.28.8 side is a worktree at c717c9cd9 (the C code of the tag), its benchmarks rebuilt against its own libraries. The two binaries of each benchmark run in rotation, the order turned every round, a sync and a 3 s pause before each run (1 s for the three ctest binaries): 8 rounds. Mean +- standard deviation (median), t = the change over its standard error; |t| < 3 is noise. The BFF figure is the mean of the Msg/sec samples of a run, the first one (the warm-up) left out, on both sides. The three figures slower outside their noise were measured again in rotations of their own: the TCP echo and the treedb save on 7.28.8, 7.28.11 and 7.29.0 (9 rounds) and on the 7.29.0 binary relinked with one or all of the libraries of 7.28.11 (10 rounds), the TLS echo on the five builds 7.28.8 to 7.29.0 (10 rounds). One round of the first of those rotations was slow on every build at once and is left out of its figures.

Absolute figures. The absolute figures of 7.29.0 are its side of the A/B run: its C code (74ad0287b), built and measured on 2026-10-28 on the machine of the earlier reports.
