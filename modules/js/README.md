# modules/js

This directory is a placeholder for optional JavaScript modules. The active JS kernel and the UI library are in `kernel/js/`. The kernel is `kernel/js/gobj-js/`, the package `@yuneta/gobj-js`, with the core GObj framework in JS. The UI library is `kernel/js/gobj-ui/`, the package `@yuneta/gobj-ui`, with the reusable UI components.

This directory stays for future JS modules that do not belong in the kernel.
